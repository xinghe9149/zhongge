# KTK_04_246B 优化版中割报告

输出帧：`midcut/A0002.tga`、`A0003.tga`、`A0004.tga`、`A0005.tga`、`A0007.tga`、`A0008.tga`。

使用 RIFEm 任意时间步模型直接推理 1/5、2/5、3/5、4/5、1/3、2/3。A0007 和 A0008 额外使用时序翻转增强（TTA）；前半段保持默认推理，避免 TTA 对小位移线条的轻微损失。所有输出经过温和线稿对比度恢复，保持 RGB 线稿而非实色渲染。

参考成品仅用于生成后的评测。线集阈值为灰度 <245，容差 F1 的距离阈值为 3 px。

| 指标 | 结果 |
| --- | ---: |
| 平均 Chamfer | 4.149 px |
| 平均容差 F1 | 0.6790 |
| 序列质心平均加速度 | 16.466 px |

逐帧：A0007 的 F1 为 0.4013，A0008 为 0.4924。大幅转头下的前发遮挡和新显露的面部区域仍是主要误差来源；自动方法能保持主要部件，但细发梢和眼部交叠仍需局部人工修线才能达到人工中割质量。
