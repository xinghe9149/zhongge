# KTK_04_246B 中割生成报告

输出：`midcut/A0002.tga`、`A0003.tga`、`A0004.tga`、`A0005.tga`、`A0007.tga`、`A0008.tga`。

## 方法

律表的 1--6 与 6--9 均为连续等间隔暴露。使用 RIFEm 任意时间步模型直接生成 1/5、2/5、3/5、4/5、1/3、2/3 时刻；每个输出再做温和的白底去雾和逐通道线条对比度恢复，保留黑、蓝、红、绿的原画线色。参考成品仅用于生成后的量化评测。

## 评测

线集阈值为灰度 <245，容差 F1 的距离阈值为 3 px。详细逐帧结果见 `evaluation.json`。

| 指标 | 结果 |
| --- | ---: |
| 平均 Chamfer | 4.227 px |
| 平均容差 F1 | 0.6784 |
| 序列质心平均加速度 | 18.344 px |

第二段 A0007/A0008 的 F1 分别为 0.3984/0.4917，仍明显低于第一段，不能视为人工中割级成品。

## 难点表现

- 大位移：第一段的小幅转动可保持外轮廓，但第二段转头幅度较大，脸部和头发出现淡线、位置偏移。
- 遮挡：前发遮挡眼睛时，网络会弱化或错连局部笔画；未新增角色部件，但细节完整性不足。
- 发丝细节：主轮廓和大束发丝多数被保留，细碎发梢在长时间递归插帧后有断裂/变淡。

要达到更高的线集指标，需要使用支持任意时间步、专门以动画线稿训练的模型，或在光流结果上加矢量描线、部件遮挡层和人工修线环节。
